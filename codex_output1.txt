噪声合成实验设计：检验近似可实现性下的非零对齐地板

一、实验目的

该实验不用于比较模型性能，而用于隔离 Proposition 2.x 中的标签歧义项。目标是检验：当 Y 在给定 X 后仍有随机性时，OPB 的 anchor mismatch 不应收敛到 0，而应随 beta 接近一个可解析的非零地板；确定性实验是噪声率为 0 的特例。

二、数据分布

1. 取 K=10，潜在干净类别 C 在 {1,...,K} 上均匀分布，输入 X=e_C in R^K。
2. 编码器只能接收 X，严禁把观测标签 Y、样本编号或噪声标记作为输入。
3. 使用对称标签噪声率 r：

   P(Y=C | C)=1-r,
   P(Y=j | C)=r/(K-1),  j != C.

4. 主实验取 r in {0, 0.1, 0.2, 0.4}。r=0 必须复现现有确定性合成实验。
5. 优先直接对全部 K x K 个 (C,Y) 组合计算带条件概率权重的总体目标，避免一次性随机翻转标签造成有限样本地板偏差。若现有训练框架只能读取样本，则对每个 C 分层生成足够多样本，并单独报告经验条件概率与理论概率的偏差。

三、模型与训练控制

1. 使用 OPB、anchor-energy head、K=d=10、tau=1、a=6。
2. 固定正交 frame Q=I 作为主结果，以排除 frame rotation。可将 trainable polar frame 作为附录稳健性结果，但不得替代固定 frame 主结果。
3. 后验均值由 one-hot linear encoder 表示，因此每个输入类别对应一个可训练均值。后验方差沿用论文模型；必须同时记录 covariance mismatch。若希望获得最干净的标签歧义验证，可额外运行 posterior variance 固定为 tau^2 的版本。
4. beta 网格沿用现有九点合成网格：{1e-3, 3e-3, 1e-2, 3e-2, 1e-1, 3e-1, 1, 3, 10}。
5. 每个配置运行 seeds 0--4。优化轮数应保证训练目标稳定；保存最后至少 20 个 epoch 的目标，检查是否仍有系统下降趋势。
6. 不按测试准确率选择 checkpoint。优先用最低验证/总体 GPB objective 的 checkpoint；同时保存最终 checkpoint 作为敏感性检查。

四、解析 comparator 与理论地板

令 eta_k(e_C)=P(Y=k | C)。正交 anchor 为 A_k=a q_k。给定 X=e_C 的条件平均 anchor 为

  h_0(e_C)=a[(1-r)q_C + r/(K-1) sum_{j!=C} q_j].

取 comparator posterior

  q_0(z|e_C)=N(h_0(e_C), tau^2 I).

其 covariance mismatch 为 0，KL 和 mean mismatch 的理论最小值均为

  delta_noise(r)
    = a^2/(2 tau^2) * [1-(1-r)^2-r^2/(K-1)].

每个 r 都必须在结果 CSV 中保存解析 delta_noise，而不是由训练结果拟合。用大规模 Monte Carlo 或对 (C,Y) 精确求和计算 comparator 在 anchor-energy head 下的预测风险 C_comp。理论参考曲线为

  delta_noise + C_comp/beta.

另外计算训练模型的目标 L_hat=R_hat+beta*K_hat 与 comparator 目标 L_comp=C_comp+beta*delta_noise。若 L_hat <= L_comp，则在相同经验/Monte Carlo 分布上可直接检查

  D_hat <= K_hat <= delta_noise + C_comp/beta.

若 L_hat > L_comp，应标记为 optimization failure，不能把超出参考线解释为理论失败。

五、必须记录的量

每个 seed、r、beta 至少保存：

- D_hat = E[||mu(X)-a q_Y||^2/(2 tau^2)]；
- 每个观测类别的 D_k；
- total KL K_hat、mean KL、covariance KL，以及 K_hat-D_hat 的数值一致性；
- prediction risk R_hat 和 objective L_hat；
- delta_noise、C_comp、L_comp、L_hat-L_comp；
- excess mismatch D_hat-delta_noise；
- beta*(D_hat-delta_noise)；
- 对观测噪声标签 Y 的 accuracy/CE；
- 对潜在干净类别 C 的 accuracy；
- posterior class-center pairwise distance、center-to-conditional-anchor error；
- trainable-frame 附加实验中的 sigma_min(U) 和正交误差。

建议 CSV 字段：seed, noise_rate, beta, anchor_scale, frame_type, posterior_var_mode, d_hat, kl_mean, kl_cov, kl_total, delta_noise, comparator_risk, trained_risk, trained_objective, comparator_objective, excess_d, beta_excess_d, noisy_label_acc, clean_class_acc, min_center_distance, mean_center_distance, min_sigma_u, failed。

六、图表与统计

主文建议一张 2 x 2 图：

(a) D_hat versus beta，并为每个 r 画 delta_noise 水平虚线；
(b) D_hat-delta_noise versus 1/beta，两个坐标轴均使用 log scale，只画正值；
(c) beta*(D_hat-delta_noise) versus beta；
(d) noisy-label accuracy 与 clean-class accuracy versus beta。

另给一张小表报告每个 r 的 delta_noise、最大 beta 时的 D_hat、D_hat-delta_noise、L_hat-L_comp。曲线和表格均报告五个 seed 的 mean +/- std；可额外给 paired bootstrap 95% CI，但不得把误差条与理论保证混为一谈。

七、成功判据与禁止表述

1. r=0 时 D_hat 应接近 0；r>0 时大 beta 下 D_hat 应接近对应的非零 delta_noise。
2. excess mismatch 应总体随 beta 减小；不要求严格单调，也不宣称精确 1/beta 定律。
3. 只有在 L_hat <= L_comp 时，才能把 delta_noise+C_comp/beta 作为该训练点的经验上界进行讨论。
4. 该实验支持的是 ambiguity floor 和 comparator mechanism，不证明真实 benchmark 的噪声率、优化误差或 comparator 风险。
5. 不得使用“验证了定理”这类表述；建议使用“controlled illustration”或“consistent with the predicted non-zero floor”。

八、可选回归补充

如计算预算允许，可增加 EPB 噪声回归：X~N(0,1)，Y=X+xi，xi~N(0,sigma_y^2)，encoder 只看 X。使用固定轴、rho=6、tau=1，并取多个 sigma_y。若不标准化标签，解析地板为 rho^2 sigma_y^2/(2 tau^2)；若按总体方差标准化 Y，则必须相应换算 Var(tilde Y|X)。该结果放附录即可，不作为完成审稿意见的必要条件。
